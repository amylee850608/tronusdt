# USDT Transfer Page Replica

This project is a pixel-perfect replica of the USDT-TRC20 Transfer page using HTML, CSS, and JavaScript.

## Files

- `index.html`: Main HTML structure.
- `style.css`: Stylesheet for the page.
- `script.js`: Basic interaction logic (Mock balance, All button, Input handling).

## How to Run

Simply open `index.html` in any modern web browser.

## Features implemented

- Responsive layout matching the screenshot.
- Interactive "All" button that fills the balance.
- Real-time USD conversion calculation (Mock rate 1:1).
- Custom icons using SVG.
